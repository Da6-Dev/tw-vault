# 👥 Comandos para Jogadores (`CommandWhitelist`)

> [!abstract] Comandos Aprovados
> Lista exata de comandos que qualquer jogador no grupo `default` tem permissão para visualizar e executar sem bloqueios.

---

## ⛏️ Jogabilidade, Minas e Ranks

| Comando | Argumentos | Descrição da Função |
| :--- | :--- | :--- |
| `/mina` ou `/mine` | *(nenhum)* | Abre menu gráfico da melhor mina liberada para o rank do jogador. |
| `/minaslista` | *(nenhum)* | Abre a central visual com todas as minas do servidor. |
| `/rankup` | *(nenhum)* | Evolui 1 rank caso possua saldo monetário suficiente. |
| `/rankupmax` | *(nenhum)* | Sobe o máximo de ranks possíveis gastando todo o saldo disponível. |
| `/prestigio` | *(nenhum)* | Abre o menu de evolução de Prestígio (Grinch, Yeti, Krampus). |
| `/ranks` ou `/rank` | *(nenhum)* | Exibe no chat a lista de ranks, custos ou progresso pessoal. |
| `/minapvp` ou `/pvp` | *(nenhum)* | Teleporta para a arena hostil com PVP ativado. |
| `/pvpsair` | *(nenhum)* | Sai da arena PvP (bloqueado se estiver em combate). |

---

## 🏭 Sistemas Industriais e Lotes

| Comando | Argumentos | Descrição da Função |
| :--- | :--- | :--- |
| `/terreno` ou `/terrenos` | `[claim/auto/home]` | Compra e gerencia plots no mundo `terrenos` por R$ 50k. |
| `/maquinas` | `[status]` | Abre o painel de máquinas industriais ou consulta o combustível. |
| `/spawners` ou `/geradores` | `[status]` | Compra geradores de monstros ou inspeciona rendimento de tokens. |
| `/farm` ou `/farms` | *(nenhum)* | Abre o painel de agricultura, silos e alquimia. |
| `/caixas` ou `/key` | *(nenhum)* | Abre caixas misteriosas ou consulta chaves disponíveis. |

---

## 🧭 Hub, Comunicação e Utilitários

| Comando | Argumentos | Descrição da Função |
| :--- | :--- | :--- |
| `/menu` ou `/ajuda` | *(nenhum)* | Abre o Menu Principal do servidor. |
| `/spawn` | *(nenhum)* | Retorna ao Spawn central no mundo `world`. |
| `/warp` ou `/warps` | `[nome]` | Teleporta para localidades públicas marcadas. |
| `/correio` | *(nenhum)* | Abre a caixa de correio virtual do jogador. |
| `/kit` ou `/kits` | `[nome]` | Abre o menu de kits diários ou resgata kits de combate. |
| `/msg <player> <msg>` | `<jogador> <texto>` | Envia mensagem privada para outro jogador. |
| `/reply <msg>` ou `/r` | `<texto>` | Responde ao último jogador que enviou `/msg`. |
| `/ignore` | `<jogador>` | Bloqueia mensagens privadas de um usuário. |
| `/discord` | *(nenhum)* | Exibe o link de convite da comunidade. |
| `/afk`, `/rules`, `/ping`, `/playtime`, `/list`, `/trash` | - | Ferramentas utilitárias gerais e lixeira virtual. |
