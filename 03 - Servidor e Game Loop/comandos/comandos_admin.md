---

## 🛠️ Comandos de Gestão de Servidor e Plugins

| Comando | Argumentos | Descrição da Função | Plugin |
| :--- | :--- | :--- | :--- |
| `/ac` | `[mensagem]` | Canal de chat de alta segurança exclusivo para Administradores. | AwesomeChat |
| `/ban` | `<jogador> [motivo]` | Bane permanentemente a conta de um jogador. | EssentialsC |
| `/unban` | `<jogador>` | Remove o banimento de uma conta. | EssentialsC |
| `/ban-ip` | `<jogador/ip> [motivo]` | Bane a faixa de IP do infrator. | EssentialsC |
| `/setspawn`| *(nenhum)* | Define o novo ponto central de aterrissagem do servidor. | EssentialsC |
| `/lp` | `<user/group> <alvo> ...` | Gerenciador de permissões, cargos e heranças do LuckPerms. | LuckPerms |
| `/rg` | `[define/flag/remove/info]`| Gerencia regiões e propriedades de proteção do WorldGuard. | WorldGuard |
| `/cw` | `[add/remove/reload]` | Modifica dinamicamente a whitelist de comandos dos jogadores. | CommandWhitelist |
| `/realmines`| `[reset/reload/create]`| Força reset de blocos e gerencia minas regenerativas. | RealMines |
| `/fn` | `[create/npc/reload]` | Gerencia criação de NPCs, skins e ações de clique. | FancyNpcs |
| `/tab` | `[reload/group/player]` | Recarrega e gerencia as tags de nametag e ordem do TAB. | TAB |
