# ⌨️ Central de Comandos e Permissões

> [!abstract] Controle de Execução
> O servidor utiliza o plugin `CommandWhitelist` para impedir que jogadores vejam comandos não autorizados no autocomplete ou tentem executar comandos fora de sua permissão.

---

## 🗂️ Categorias de Comandos

- [[comandos_jogadores|👥 Comandos para Jogadores]]: Lista whitelisted completa de comandos acessíveis pelo grupo `default`.
- [[comandos_economia|💵 Comandos de Economia]]: Transferências, cheques, saldo, lojas e rankings.
- [[comandos_staff|🛡️ Comandos de Moderação]]: Punições temporárias, fiscalização, silenciamentos e canais de staff.
- [[comandos_admin|👑 Comandos de Administração]]: Comandos avançados de gerenciamento de plugins, permissões e economia forçada.
