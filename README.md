## 📖 Sobre o Super-Vault

Este repositório é o **Segundo Cérebro** unificado da rede **TW Network**. Ele consolida em um único cofre Obsidian as especificações e decisões técnicas de todos os projetos da organização:

1. **🌐 01 - Web & Loja:** Plataforma web React 19 / Vite 8, API Express 5, autenticação JWT, gateway Mercado Pago e banco de dados Neon PostgreSQL.
2. **🧩 02 - Plugins Java:** Engenharia dos 9 módulos proprietários Java (`tw-core`, `tw-ranks`, `tw-minas`, etc.), regras de concorrência e PDC.
3. **🎮 03 - Servidor & Game Loop:** Balanceamento econômico in-game, menus, NPCs, mundos e comandos de jogadores e equipe.
4. **📅 04 - Diário de Bordo:** Registro cronológico de deploy e arquitetura da rede.

## 🧭 Como Usar no Obsidian

1. Abra o aplicativo **[Obsidian](https://obsidian.md/)**.
2. Clique em **Open folder as vault** (Abrir pasta como cofre).
3. Selecione a pasta deste repositório (`tw-vault`).
4. Pressione **`Ctrl + G`** para abrir o **Graph View** e explore as conexões visuais entre todas as partes da rede!
